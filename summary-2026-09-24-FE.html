End-to-End FlowFlow แบบครบวงจร

  • Understood the overall Subscription flow: select product → select Power → check Inventory → create Order → next Shipment round → Recurring Payment, until cancelled. เข้าใจภาพรวม Subscription Flow ตั้งแต่เลือกสินค้า → เลือก Power → ตรวจสอบ Inventory → สร้าง Order → Shipment รอบถัดไป → Recurring Payment จนกว่าจะยกเลิก

Backend-Driven Dataข้อมูลขับเคลื่อนจาก Backend

  • Understood that Backend/API sends the core data and business logic to FE — e.g. Supply Duration, number of boxes, Discount, Delivery Option, Status, and various Flags — with FE just displaying it as the API provides. เข้าใจว่า Backend/API จะส่งข้อมูลและ Business Logic หลักมาให้ FE เช่น Supply Duration, จำนวนกล่อง, Discount, Delivery Option, Status และ Flags ต่าง ๆ โดย FE นำข้อมูลมาแสดงตาม API

Contact Lens + PowerContact Lens + Power

  • Understood that each Power is tied to a different PID / JAN Code / Gencode, and Power must be selected first before the correct Stock can be checked. เข้าใจเรื่อง Contact Lens + Power ว่าแต่ละ Power จะผูกกับ PID / JAN Code / Gencode ที่แตกต่างกัน และต้องเลือก Power ก่อนจึงจะตรวจสอบ Stock ที่ถูกต้องได้

Subscription ConfigurationSubscription Configuration

  • Understood Subscription Configuration — Lead Time, Payment Method, Promotion, and creating the next Order round — all of which can be adjusted per country. เข้าใจ Subscription Configuration เช่น Lead Time, Payment Method, Promotion และการสร้าง Order รอบถัดไป ซึ่งสามารถปรับตามแต่ละประเทศได้

Parent Subscription vs. ShipmentParent Subscription กับ Shipment

  • Understood the relationship between Parent Subscription and Shipment — each Shipment round is tied to the same Parent Subscription, and Subscription-level actions vs. Shipment-level actions are handled through separate Entities. เข้าใจความสัมพันธ์ระหว่าง Parent Subscription และ Shipment โดย Shipment แต่ละรอบจะถูกผูกกับ Parent Subscription เดียวกัน และ Action ระดับ Subscription กับ Shipment จะจัดการผ่านคนละ Entity

Subscription State / FlagsSubscription State / Flags

  • Understood Subscription State / Flags such as Active, Processing, and Cancelled — FE uses the data from Backend to control what's shown in the UI. เข้าใจ Subscription State / Flags เช่น Active, Processing, Cancelled และ FE จะใช้ข้อมูลจาก Backend เพื่อควบคุมการแสดงผลของ UI
