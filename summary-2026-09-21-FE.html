WARRANTY Singapore Online Platform

Requirement & ScopeRequirement & Scope

  • Reviewed and understood the requirement and scope of Warranty for the Singapore Online Platform. ทบทวนและทำความเข้าใจ Requirement และ Scope ของ Warranty สำหรับ Singapore Online Platform
  • Dependencyมี Dependency Learned the warranty conditions for Lens, Progressive Lens, and Sale Items, including the parts that depend on Front2. เรียนรู้เงื่อนไข Warranty ของ Lens, Progressive Lens และ Sale Item รวมถึงส่วนที่มี Dependency กับ Front2

From Static Info to a Real, Order-Linked Featureจาก Static Information สู่ระบบที่ผูกกับ Order จริง

  • Understood the direction for rebuilding Warranty — from static information into something linked to Orders and the database, so it can show Warranty Status, Expiration Date, and coverage details. เข้าใจแนวทางการทำระบบ Warranty จากเดิมที่เป็น Static Information ให้เชื่อมกับ Order และ Database เพื่อแสดง Warranty Status, Expiration Date และรายละเอียดการรับประกัน
  • Understood the new post-order flow: the Order Listing will show Warranty Status, with details viewable through a Warranty Sidebar. ทำความเข้าใจ New Post-Order Flow โดย Order Listing จะแสดง Warranty Status และสามารถกดดูรายละเอียดผ่าน Warranty Sidebar
  • The Sidebar needs to be built as a reusable component, so it works for both Order Listing and Order Detail. Sidebar ต้องทำเป็น Reusable Component เพื่อใช้ได้ทั้ง Order Listing และ Order Detail

Technical Approachแนวทางทางเทคนิค

  • Learned the technical requirements: API Integration, Feature Flag, Mock Data, and Shared UI Kit. เรียนรู้ Technical Requirement เช่น API Integration, Feature Flag, Mock Data และ Shared UI Kit
  • Working approachแนวทางการทำงาน While waiting for the real API, start building with Mock Data, then switch to real data once the API is ready. ระหว่างรอ API จริง ให้เริ่มพัฒนาด้วย Mock Data และเมื่อ API พร้อมจึงเปลี่ยนไปใช้ข้อมูลจริง
  • Working approachแนวทางการทำงาน For design, start implementing based on the existing design first, so development isn't blocked while waiting for the final Figma. สำหรับ Design ให้เริ่ม Implement เบื้องต้นตาม Design เดิมไปก่อน เพื่อไม่ให้ Development Block ระหว่างรอ Final Figma
  • Pending confirmationรอ Confirm เพิ่มเติม Some details are still pending confirmation, such as Accordion/Popup behavior and how to display multiple warranties. มีบางรายละเอียดที่ต้องรอ Confirm เพิ่มเติม เช่น Accordion/Popup และการแสดงผลกรณีมีหลาย Warranty
