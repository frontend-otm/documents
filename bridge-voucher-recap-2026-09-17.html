Rule Engine Overviewภาพรวม Rule Engine

  • Learned the overall workings of Bridge, which uses rule-based logic to detect abnormal behavior in Orders, Returns, and Refunds — e.g. unusually frequent ordering, or discount usage above the allowed threshold. เรียนรู้ภาพรวมการทำงานของ Bridge ซึ่งใช้ Rule-based logic เพื่อตรวจจับพฤติกรรมที่ผิดปกติใน Order, Return และ Refund เช่น การสั่งซื้อถี่ผิดปกติหรือการใช้ Discount สูงเกินกำหนด

Gift Voucher & Discount Rule Setupตั้งค่า Gift Voucher & Discount Rule

  • Learned how to set up a Gift Voucher (GV) and Discount Campaign — from creating the GV to setting its usage type: Single-use / Multiple-use. เรียนรู้การตั้งค่า Gift Voucher (GV) และ Discount Campaign ตั้งแต่การสร้าง GV กำหนดประเภทการใช้งาน Single-use / Multiple-use
  • Learned how to create and edit Discount Rules, with conditions settable by Country, Exchange Order, Item, SKU, and Lens Package. เรียนรู้การสร้างและแก้ไข Discount Rules โดยสามารถกำหนดเงื่อนไขตาม Country, Exchange Order, Item, SKU และ Lens Package ได้
  • Learned how to use Cart Conditions and Item-level Conditions to check whether a given product/SKU is in the cart, and to control whether a discount applies to specific items only or the whole cart. เรียนรู้การใช้ Cart Conditions และ Item-level Conditions เพื่อตรวจสอบว่าสินค้าหรือ SKU ที่กำหนดอยู่ใน Cart หรือไม่ และกำหนดได้ว่าส่วนลดจะ Apply เฉพาะบาง Item หรือทั้ง Cart
  • Learned how to set Priority and Naming Convention for Discount Rules, to manage and tell rules apart systematically. เรียนรู้การกำหนด Priority และ Naming Convention สำหรับ Discount Rules เพื่อให้สามารถจัดการและแยกแยะแต่ละ Rule ได้อย่างเป็นระบบ

Testing, Publishing & Production ChecksTest, Publish & ตรวจสอบ Production

  • Learned the Publish process to test a rule before it goes live — a target customer group or test data can be set without needing to create a real order. เรียนรู้กระบวนการ Publish เพื่อทดสอบ Rule ก่อนใช้งานจริง โดยสามารถกำหนดกลุ่มลูกค้าหรือข้อมูลสำหรับ Test โดยไม่จำเป็นต้องสร้าง Order จริง
  • Learned how to check discount results when multiple rules run at once, including cases where the discount is distributed proportionally across cart items. เรียนรู้วิธีตรวจสอบผลลัพธ์ของ Discount เมื่อมีหลาย Rules ทำงานพร้อมกัน รวมถึงกรณีที่ส่วนลดถูกกระจายตามสัดส่วนของสินค้าแต่ละรายการ
  • Learned how to review Production Rules — both Enabled and Disabled — and export the data to filter and analyze the configuration currently in use. เรียนรู้การตรวจสอบ Production Rules ทั้ง Rule ที่ Enabled และ Disabled รวมถึงการ Export ข้อมูลเพื่อนำไป Filter และวิเคราะห์ Configuration ที่ใช้งานอยู่
  • Things to watch forข้อควรระวัง Understood the limitations to watch out for: UI/Backend access rights, the scheduling system's time zone, and the difference between Test Configuration and Production Configuration. ได้เข้าใจข้อจำกัดและสิ่งที่ต้องระวังในการทำงาน เช่น สิทธิ์ในการเข้าถึง UI/Backend, Time Zone ของระบบ Scheduling และความแตกต่างระหว่าง Test Configuration กับ Production Configuration
