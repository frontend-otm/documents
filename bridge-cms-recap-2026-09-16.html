CMS / LPCMS / LP

  • Learned the 2 static LP formats: an Image/Video Widget, and an HTML-based LP that supports Actions, Hover, and Animation. Widgets can be built and dropped into a Collection Template, per the Training Manual. เข้าใจ Static LP 2 รูปแบบ: Image/Video Widget และ HTML-based LP ที่รองรับ Action, Hover และ Animation โดย Widget สามารถสร้างและนำไปใส่ใน Collection Template ได้ตาม Training Manual
  • Interactive LPs (e.g. POMPOMPURIN) can be built as a full standalone HTML page — likely the format JP will want more of. LP แบบ Interactive เช่น POMPOMPURIN สามารถทำเป็น HTML แยกทั้งหน้าได้ ซึ่งน่าจะเป็นรูปแบบที่ JP ต้องการมากกว่า
  • Gapช่องว่างที่พบ T&M wants a CMS that lets them publish an LP themselves, but LK doesn't have that capability yet. ทีม T&M ต้องการ CMS ที่ publish LP ได้เอง แต่ปัจจุบัน LK ยังไม่มีฟังก์ชันนี้
  • Gapช่องว่างที่พบ The Lens Selection Modal can't yet reuse the shared component from the central system — each LP still needs its own HTML + function rewritten from scratch. Lens Selection Modal ยังใช้ Shared Component จากระบบกลางไม่ได้ ต้องเขียน HTML + Function ใหม่ในแต่ละ LP
  • Bugพบปัญหา Successfully created a CMS page on Preprod, but Preview doesn't render the LP there — Preview does work correctly on Production. ทดลองสร้าง CMS บน Preprod สำเร็จ แต่ Preview ไม่สามารถแสดง LP ได้ ในขณะที่ฝั่ง Production Preview ใช้งานได้ปกติ
