API GAPS Things Backend Isn't Ready For Yetสิ่งที่ Backend ยังไม่พร้อม

Gaps to Confirm with BEGap ที่ต้องยืนยันกับ BE

  • Imagesรูปภาพ items[].image and universalServices.terms[].imageUrl are still empty, so product images and Universal Services icons aren't ready yet. items[].image และ universalServices.terms[].imageUrl ยังเป็นค่าว่าง ทำให้รูปสินค้าและ Icon ของ Universal Services ยังไม่พร้อม
  • Universal ServicesUniversal Services The API only returns 1 item, while Design needs 3, and the description received looks copied from frame_warranty — using 3 items of Mock Data per Design for now. API ส่งมาเพียง 1 รายการ จากที่ Design ต้องการ 3 รายการ และ Description ที่ได้รับดูเหมือนถูก Copy มาจาก frame_warranty จึงยังใช้ Mock Data 3 รายการตาม Design ไปก่อน
  • StatusStatus Currently only ACTIVE has been seen — no EXPIRED value yet, so need to confirm with BE what the status value for an expired warranty should be. ปัจจุบันพบเฉพาะ ACTIVE ยังไม่พบค่า EXPIRED จึงต้องยืนยันกับ BE ว่าค่า Status สำหรับ Warranty ที่หมดอายุควรเป็นอะไร
  • FootnoteFootnote Footnote is currently tied to each Warranty, not at the Order level, and the sample only has damage_protection. FE currently merges all unique footnotes into a Disclaimer shown below, but still needs BE to confirm this is the correct behavior. ปัจจุบัน Footnote ผูกอยู่กับแต่ละ Warranty ไม่ใช่ระดับ Order และใน Sample มีเฉพาะ damage_protection โดยตอนนี้ FE รวม Footnote ที่ไม่ซ้ำกันทั้งหมดมาแสดงเป็น Disclaimer ด้านล่างก่อน แต่ยังต้องยืนยันกับ BE ว่านี่เป็น Behavior ที่ถูกต้องหรือไม่
  • API ContractAPI Contract The endpoint using name=OD_WARRANTY_SAMPLE looks like a static AB-config lookup, not yet tied to orderId/itemId — need to confirm with BE whether this is the real Production API contract or just a placeholder for parallel FE development. Endpoint ที่ใช้ name=OD_WARRANTY_SAMPLE ดูเหมือนเป็น Static AB-config lookup และยังไม่ได้ผูกกับ orderId/itemId จึงต้องยืนยันกับ BE ว่านี่คือ API Contract จริงสำหรับ Production หรือเป็นเพียง Placeholder สำหรับการพัฒนา FE แบบ Parallel กันก่อน
